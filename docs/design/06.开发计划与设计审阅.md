## 2. 实现与设计的对应

后端位于 `backend/`（Maven、Java 21、Spring Boot 3.5.16），包 `com.dreame.qd`：

| 设计 | 实现 |
|---|---|
| 分层（02 3.2、04 1.1） | `trigger` / `service` / `rule` / `integration.jira` / `integration.feishu` / `integration.local` / `model` / `config` |
| EXT-J01、INT-05 | `HttpJiraClient`：分页、`RateLimiter`（≤90 次/分钟）、状态码 → `QD-JIRA-001…005`（401/403 不重试，403 验证码单独提示） |
| EXT-F01～F07 | `FeishuHttp`（令牌缓存）、`BitableClient`（分页 / 分批 500）、`BitableTaskTableGateway`（13 字段）、`AdminConfigRepository`、`FeishuContactGateway`（≤50 个邮箱/批）、`FeishuMessageGateway` |
| EXT-F08、EVT-01 | `LongConnectionListener`（SDK 长连接）、`SyncRequestParser`（解析卡片 `user_dsl`）、`ManualSyncHandler`（独立线程、消息 ID 去重、同步中忽略） |
| INT-01～03 | `ScheduledJobs`（09:00 / 16:50 / 17:00 / 每周一日历检查，北京时间，成功才记录 `runs`）、`CatchUpRunner`（02 Q8）、`WorkdayCalendar` |
| INT-04 | `SyncService`：单把锁、重试 1 次（`RetryExecutor`）、新增 → 更新 → 删除、失败不改表并通知 |
| INT-08～10 | `AccountMapper`、`RecipientResolver`、`ReminderComposer`（纯规则） |
| INT-11、12 | `ReminderService`（每人每天 1 条、重试 1 次、`uuid` 去重）、`AlertService`（同时通知两人，通知失败不递归） |
| INT-13 | `DailyStateStore`（`reminder-state.json`，原子写入，损坏按空状态） |
| 启动校验（04 Q4） | `ConfigValidator` + `AppConfig`：缺项即**拒绝启动**并列出全部错误；飞书配置可用时同时私聊运维 / 备份 |
| 运行日志（02 Q7） | `logback-spring.xml`：本地文件、保留 7 天；代码中不记录密码、令牌、请求体、Authorization |

测试：`mvn test` 共 43 个用例（规则、服务、触发、集成层 HTTP 模拟），全部通过；启动时缺配置会拒绝启动已手工验证。

## 3. 联调前须完成（非代码）

1. **建表**（飞书）：按 03 第 2、3 章建主表格（13 个字段、5 个视图、仪表盘）与管理表格（排除名单、例外对应表、节假日日历）；QD助手 以可管理身份加入（03 2.5，需确认不受记录条件限制）。联调阶段可先用个人空间的测试表格，**不动正式表格**。
2. **填写配置**：复制 `deploy/local/config/application.yml.example` 为 `application.yml`，填入 `app_token`、`table_id`、`view-mine-url`、运维 / 备份 `open_id`。
3. **设置环境变量**：`QD_FEISHU_APP_SECRET`、`QD_JIRA_USERNAME`、`QD_JIRA_PASSWORD`（只在本机设置，不进仓库、不贴进对话）。
4. **仪表盘按钮的工作流**：点击后向 QD助手 所在群发送文本 `#QD立即同步` 的卡片消息（03 2.4、V3）。
5. **应用可用范围**：覆盖全部提醒对象（D3，朱卓处理）。
6. 首次联调顺序：只读验证（Jira 拉取）→ 手动同步写测试表 → 给自己发 17:00 提醒 → 再开放定时。

## 3A-2. 新增「描述」「评论」字段（2026-11-27）

用户新需求：主表与副本表各新增「描述」「评论」两个多行文本字段，来源于 Jira 问题页面。已确认：评论取**全部评论**；文字转**纯文本**。实现：Jira 查询增加 `description,comment` 并带 `expand=renderedFields`，渲染后的 HTML 经 jsoup 转纯文本（`HtmlText`）；评论按时间从旧到新、带作者与北京时间；描述超 2 万字、评论合计超 5 万字截断并标注（实测评论合计最大约 1.8 万字）；写表单批改为 100 行。接口层新增 `JiraComment`，`JiraIssue` / `TaskRow` 增加两个成员（保留旧构造，现有调用不受影响）。字段已用接口加到两张表；03（2.1 第 13、14 项、4.1、4.2）、04 已同步。单元测试 55 个全部通过。**待验证**：真实同步后两张表的内容与已有 420 余条记录的补填。

## 3B. 部署包（2026-11-27）

`deploy/package/build-package.ps1` 构建 `dist/qd-assistant-<版本>.zip`（`dist/` 已加入 `.gitignore`）。包内容：`qd-assistant.jar`（自包含）、`start.ps1`（检查 Java 21+、配置、三个 `QD_` 环境变量、单实例，`-CheckOnly` 只检查）、`install-task.ps1` / `uninstall-task.ps1`（登录后自启的计划任务，失败自动重启 5 次）、`config/application.yml.example`、`README.md`（部署、升级、运维步骤）。运行环境：Windows + Java 21+，无需数据库与公网地址。

已验证：包可构建（含 49 个测试）；在临时目录里 `start.ps1 -CheckOnly` 对"缺配置文件"报错退出、对"已有实例在运行"给出警告。**未验证**：`install-task.ps1` 实际注册计划任务（不想在联调机上替用户注册）、在另一台干净机器上的完整部署。仍未做：容器镜像（若迁到内网服务器 / 容器平台再做，见 02 R9）。部署前需先确定长期运行的机器，并按包内 README 设置环境变量与"不休眠"电源计划。
