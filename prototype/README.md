# QD助手 · Jira 未完成任务提醒 —— 可交互原型

依据 [`docs/需求文档.md`](../docs/需求文档.md)（v1.0）制作的纯前端可交互原型，**全部为模拟数据**，不连接真实 Jira 与飞书。

## 打开方式

直接用浏览器打开 `prototype/index.html` 即可；或在项目根目录运行：

```
python -m http.server 8765 --directory prototype
```

然后访问 http://localhost:8765 。

## 页面构成

| 区域 | 对应需求 | 说明 |
|---|---|---|
| 顶部控制台 | —（原型专用） | 切换**当前身份**、**模拟日期**，手动触发 09:00 / 16:50 / 17:00 定时任务，模拟同步失败 |
| 📊 主表格 | F1、F2、第 5 章 | 12 个只读字段、5 个视图、"立即同步"按钮（仅管理员/负责人）、视图使用说明 |
| 💬 飞书消息 | F3、F5、第 6 章 | 当前身份收到的机器人私聊：17:00 提醒卡片、同步失败通知、未送达汇总 |
| ⚙️ 管理表格 | F4 | 排除名单、例外对应表、节假日日历；仅胡桓康、朱卓可访问 |
| 🧪 模拟 Jira | —（原型专用） | 模拟数据源，可改状态 / 经办人 / 是否在看板 / 删除 / 新建，用于观察同步效果 |

## 推荐演示路径

1. **每日提醒**：点「▶ 17:00 发送提醒」→ 打开「飞书消息」。身份为胡桓康或朱卓时，可看到"未送达汇总"（两人同时收到）。
2. **未对应人员（Q1）**：主表格「按人员查看」中，陈晨、孙伟显示 Jira 姓名并带"未对应"标签，不会出现在任何人的"我的未完成"里。
3. **例外对应**：在「管理表格 › 例外对应表」把陈晨（chenchen）对应到飞书账号陈晨 →"未对应"标签消失 → 点「下一天」→「▶ 17:00」→ 切换身份为陈晨查看。
4. **只保留未完成**：在「模拟 Jira」把某任务改为"已解决"或取消"在看板中" → 回到主表格点「立即同步」→ 该任务从表格消失；结果条标明【手动同步】，显示至下一次手动同步（Q7）。
5. **权限**：切换身份为李明 → "立即同步"不可用、管理表格无权限；胡桓康、朱卓可以立即同步（Q2）。
6. **同步失败**：控制台"下次同步"选"失败" → 「▶ 16:50」→「▶ 17:00」→ 胡桓康和朱卓同时收到失败通知（Q3），提醒照常发出并注明"数据截至"上一次成功同步。
7. **发送重试（Q4）**：控制台"17:00 发给王芳"选"首次出错，重试成功"或"出错（重试后仍失败）"→「▶ 17:00」，观察王芳是否收到、是否进入未送达汇总。
8. **法定工作日**：日期选 2026-11-27（示例节假日）→ 不同步、不提醒；选 2026-11-29（示例调休补班，周日）→ 照常执行。
9. **日历未录入（Q6、Q8）**：日期选 2026-12-07（周一）→ 在「管理表格 › 节假日日历」删除 2027 年记录 → 点「▶ 09:00」→ 两人收到"请录入次年节假日日历"；日期选 2027 年任意日期时，顶部显示"该年日历未录入，按周一至周五判断"。

## 与设计文档的对应

原型已按 [`docs/design/01.功能模块梳理.md`](../docs/design/01.功能模块梳理.md) v0.2 的审核结论更新：

| 结论 | 原型表现 |
|---|---|
| Q1 人员展示 | 经办人 / 报告人按飞书人员显示；未对应者显示 Jira 姓名 +"未对应"标签；"我的未完成"按飞书人员筛选 |
| Q2 立即同步权限 | 胡桓康（管理员）、朱卓（所有者）可操作 |
| Q3 异常通知 | 同步失败通知、未送达汇总、日历提醒同时私聊胡桓康与朱卓 |
| Q4 发送重试 | 发送出错自动重试 1 次，仍失败才计入未送达 |
| Q5 数量为 0 | 显示"共 0 条" |
| Q6 日历缺失 | 未录入年份按周一至周五判断，并在顶部和节假日日历页提示 |
| Q7 手动同步结果 | 所有查看者可见，标明【手动同步】，显示至下一次手动同步，不可关闭 |
| Q8 年底日历检查 | 12 月 1 日起每周一 09:00 检查次年日历，未录入则提醒；录入后不再提醒 |

## 其他说明

- 不记录日志：原型中只有右下角的临时提示（演示用），产品本身不保存任何日志。
- 手动同步时间取电脑当前时间（日期取模拟日期）。
- 节假日日历为示例数据：2026-11-27、2026-11-29 仅为演示，正式需按国务院公布的安排录入。
- 人员、Issue、邮箱均为虚构，邮箱统一使用 example.com。
- "17:00 发给王芳""下次同步"等控制项只用于演示异常，不是产品功能。
